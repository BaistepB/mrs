# СПЕЦИФИКАЦИЯ ПРИЛОЖЕНИЯ «МАРШРУТ ЭКСПЕРТА»

Приложение представляет собой автономное веб-приложение (SPA) для планшетов и смартфонов (React 18 + Tailwind CSS + Lucide Icons + Tesseract.js в едином файле `index.html`). Контейнер интерфейса ограничен по ширине (`max-w-[680px] mx-auto`).

## Неприкосновенный функционал приложения:

1. **Шапка (Header)**:
   - Название приложения «Маршрут эксперта» и живые часы (`ДЕНЬ.МЕСЯЦ.ГОД` и `ЧЧ:ММ:СС`).
   - Кнопка «Новый день» (сбрасывает загруженные фото и список адресов с подтверждением).

2. **Блок загрузки изображений**:
   - Поддержка загрузки одного или нескольких файлов (`<input type="file" accept="image/*" multiple>`).
   - Поддержка вставки скриншота из буфера обмена (глобальное событие `paste` + отдельная кнопка «Вставить из буфера»).
   - Отображение миниатюр загруженных скриншотов с кнопкой удаления каждого фото.

3. **Распознавание текста (OCR) и парсер заявок**:
   - Используется клиентская библиотека `Tesseract.js` (через CDN, язык `rus`) с отображением прогресс-бара распознавания в процентах.
   - **Формат входных данных со скриншота**: табличный список заявок, где слева указаны дата/время (`11.11.26 12:00`), в первой строке заявки идет номер и адрес через `|` (`№ 26-056263 | г Москва| ул Большая Черёмушкинская| д 9| к 2`), а во второй строке — адрес через запятую (`г Москва, ул Большая Черёмушкинская, д 9, к 2`).
   - **Правила очистки и дедупликации**:
     - Парсер извлекает строки с адресами (`г`/`г.` + улица/проспект/переулок/шоссе/бульвар/площадь + дом/корпус).
     - Заменяет разделители `|` на `, `, удаляет номер заявки в начале (`№ ...`), удаляет номер квартиры в конце (`, кв. ...`, `, кв ...`).
     - Убирает дубликаты (так как на скриншоте адрес каждой заявки встречается дважды), оставляя один чистый адрес на заявку.
     - Извлекает время визита (`ЧЧ:ММ`) для отображения в бейдже карточки.
   - Сворачиваемый блок «Исходный текст распознавания» под списком точек.

4. **Маршрутный лист (Список точек)**:
   - Карточки адресов с порядковым номером и бейджем времени визита.
   - Редактируемое поле `<input type="text">` в каждой карточке для быстрой правки текста.
   - Кнопки перемещения точки вверх (`↑`) и вниз (`↓`), а также кнопка удаления (`✕`).
   - Кнопка «+ Добавить адрес вручную».
   - Настройки старта и финиша:
     - Переключатель точки старта: «Моё текущее местоположение» (по умолчанию) или «Указать адрес старта» (открывает поле ввода).
     - Чекбокс «Вернуться в точку старта в конце маршрута».
   - Автосохранение списка адресов и настроек старта в `localStorage`.

5. **Интеграция с веб-версией Яндекс Карт**:
   - Главная кнопка внизу экрана: «Открыть маршрут в Яндекс Картах» (желтый акцент `#FFCC00`, черный текст).
   - Формирует URL: `https://yandex.ru/maps/?rtext=СТАРТ~ТОЧКА_1~ТОЧКА_2&rtt=auto`.
   - При выборе «Моё текущее местоположение» первый сегмент до тильды оставляется пустым (`?rtext=~Адрес1~Адрес2`).
   - Все адреса кодируются через `encodeURIComponent()`, ссылка открывается в новой вкладке (`window.open(url, '_blank')`).
